## 1. Обзор

**«Мой день»** — простой и красивый планировщик на один день. Пользователь за несколько секунд записывает задачи, отмечает выполненные и видит, сколько уже сделано. Никакой регистрации и лишних настроек: открыл страницу и работаешь.

## 2. Проблема и цель

**Проблема.** Большинство планировщиков перегружены функциями (проекты, теги, команды), из-за чего простой список дел превращается в рутину.

**Цель.** Дать минимальный, приятный на вид инструмент, в котором добавить, выполнить и удалить задачу можно за одно-два касания.

**Что считаем успехом**
- Первая задача добавляется менее чем за 10 секунд после открытия страницы.
- Данные не теряются при перезагрузке страницы.
- Интерфейс одинаково удобен на телефоне и компьютере.

## 3. Целевая аудитория

- Люди, которым нужен быстрый список дел на сегодня без лишнего функционала.
- Студенты и сотрудники, планирующие рабочий или учебный день.
- Пользователи мобильных устройств, которым важен удобный интерфейс на маленьком экране.

## 4. Пользовательские сценарии

1. **Планирование утра.** Я открываю страницу и записываю 5 задач на день.
2. **Работа в течение дня.** Я выполняю дело и отмечаю его, чтобы видеть прогресс.
3. **Ошибка или передумал.** Я удаляю ненужную задачу.
4. **Уборка вечером.** Я одним нажатием очищаю все выполненные задачи.
5. **Фокус.** Я переключаюсь на «Активные», чтобы видеть только оставшееся.

## 5. Функциональные требования

| ID | Требование | Приоритет |
|---|---|---|
| F1 | Добавление задачи через поле ввода (кнопка «Добавить» или Enter) | Must |
| F2 | Пустые задачи (только пробелы) не добавляются | Must |
| F3 | Отметка задачи как выполненной / невыполненной (клик по кружку или тексту) | Must |
| F4 | Выполненная задача визуально отличается: зачёркнутый текст, галочка ✓ | Must |
| F5 | Удаление отдельной задачи (кнопка ×) | Must |
| F6 | Новые задачи появляются в начале списка | Should |
| F7 | Фильтры: «Все», «Активные», «Выполненные» | Should |
| F8 | Индикатор прогресса: шкала, «N из M», процент | Should |
| F9 | Счётчик оставшихся задач | Should |
| F10 | Кнопка «Удалить выполненные» (видна, только если такие есть) | Should |
| F11 | Сохранение задач в браузере (localStorage) между сессиями | Must |
| F12 | Отображение текущей даты (день недели, число, месяц) на русском языке | Could |
| F13 | Пустые состояния с подсказками («Добавьте первую задачу 🌷») | Could |

## 6. Нефункциональные требования

- **Производительность:** мгновенный отклик интерфейса, без загрузки данных с сервера.
- **Адаптивность:** корректная работа на экранах от 320 px, учёт безопасных зон на смартфонах.
- **Темы:** автоматическая светлая и тёмная тема по настройкам системы.
- **Надёжность:** страница работает, даже если localStorage недоступен (данные просто не сохраняются).
- **Безопасность:** текст задач выводится как текст, а не как HTML (защита от XSS).
- **Ограничения:** длина задачи — до 120 символов.
- **Язык интерфейса:** русский.

## 7. Дизайн

- **Стиль:** современный, мягкий, с крупными скруглениями и лёгкими тенями.
- **Палитра (цветочная):** розовый и сиреневый акценты, пудровый фон, глубокий сливовый текст. На фоне мягкие размытые «лепестки» розового, лавандового и светло-зелёного цветов.
- **Тёмная тема:** тёплые бордовые и фиолетовые оттенки.
- **Заголовок:** градиентный текст «Мой день» с эмодзи 🌸.
- **Анимации:** плавное появление новых задач, плавное заполнение шкалы прогресса, hover-эффекты на кнопках.

## 8. Техническое решение

| Аспект | Решение |
|---|---|
| Формат | Один самодостаточный HTML-файл |
| Технологии | HTML, CSS (переменные для тем), чистый JavaScript без фреймворков |
| Хранение данных | `localStorage`, ключ `my-day-tasks` |
| Модель задачи | `{ id, text, done }` |
| Зависимости | Нет (без внешних библиотек и сетевых запросов) |
| Хостинг | Публикация как артефакт Claude |

## 9. Вне рамок текущей версии

- Учётные записи и синхронизация между устройствами.
- Напоминания и уведомления.
- Совместная работа.
- Планирование на другие дни и календарь.

## 10. Идеи для развития

- Редактирование текста задачи.
- Приоритеты и цветовые метки.
- Время или срок выполнения задачи.
- Категории (работа, дом, учёба).
- Перетаскивание для изменения порядка.
- Выбор цветовой темы вручную (цветочная, мятная, персиковая).
- Экспорт и импорт списка.
- Праздничный эффект при выполнении всех задач.

## 11. Критерии приёмки

- [x] Можно добавить задачу кнопкой и клавишей Enter.
- [x] Пустую задачу добавить нельзя.
- [x] Задачу можно отметить и снять отметку.
- [x] Задачу можно удалить.
- [x] После перезагрузки страницы задачи остаются.
- [x] Фильтры показывают корректные списки.
- [x] Прогресс и счётчик обновляются при любом изменении.
- [x] Интерфейс корректно выглядит на телефоне и в тёмной теме.

## 12. Метрики (для будущих версий)
